Before anyone installs (admin, one-time)

  1. Confirm the logo is live as a PNG. The signature loads it from
    https://mcgillcalisthenics.vercel.app/images/logonotext.png
    Paste that into a browser — if the logo appears, you're set. (It's already in the repo at public/images/logonotext.png; just make sure the deploy is live. Outlook cannot display WebP, which is why we use the PNG, not the .webp.)
  2. Share this kit with anyone who needs the signature.

Install in Outlook (each person)

Classic Outlook for Windows — most reliable

  1. Close Outlook.
  2. Press Win + R, type %appdata%\Microsoft\Signatures, press Enter.
  3. Fill in your four fields in signature.html, then save a copy of it into that folder as McGill.htm (simple name, no spaces).
  4. Reopen Outlook → File → Options → Mail → Signatures → set McGill as default for new mail and replies.

New Outlook for Windows & Outlook on the web

  1. Open signature.html in a browser, select the rendered signature, copy it.
  2. Go to Settings (gear) → Mail → Compose and reply → Email signature.
  3. Paste into the box, set it as default for new messages and replies, Save.

Outlook for Mac & Gmail

  1. Open signature.html in a browser (filled in), select all, copy the rendered signature.
  2. Outlook Mac: Settings → Signatures → +. Gmail: gear → See all settings → Signature → Create new.
  3. Paste, name it McGill, set as default, save.

Good to know

  • Font: the signature requests Poppins with safe fallbacks (Segoe UI → Helvetica → Arial). Most email apps don't load web fonts, so on those it shows the clean fallback — spacing and layout stay identical either way. This is normal and expected for email.
  • Edit only the [BRACKETS] — never retype or restyle the rest.
  • Never paste a screenshot of a signature again — that's what caused the distortion. This stays as live HTML + one logo image.
  • Square corners in Classic Outlook are normal — it ignores rounded corners. Everyone else sees the rounded card.
  • Update once, everywhere: change the logo file at that URL and every signature updates automatically.
